# MCP_DEMO 项目文件整理

> 本文把项目里的 11 个 Python 文件分成 **两类**：
> 1. **辅助 / 演示型文件**——单独演示某项技术（FC、Agent），并不参与 MCP 客户端/服务端的最终运行
> 2. **MCP 完整功能所需文件**——真正组成"启动 MCP 服务端 + 连接 MCP 客户端"这条主链路的所有文件
>
> 通俗理解：**第一类**就像"驾驶课上学开车"，**第二类**才是真正"上路跑运输"。

## 一、辅助 / 演示型文件（不参与 MCP 最终运行）

### 2.2 服务端（3 个文件）

服务端**只启动一个进程**，但代码被拆成 3 个文件，按职责分离。

#### ① [mcp_demo/main.py](file:///D:/BaiduNetdiskDownload/AI%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%B7%A5%E7%A8%8B%E5%B8%88/02_%E5%BA%94%E7%94%A8%E7%AF%87/11_%E5%9F%BA%E4%BA%8EMCP%E7%9A%84Agent%E5%BC%80%E5%8F%91/00_%E8%AF%BE%E7%A8%8B%E8%B5%84%E6%96%99/MCP_DEMO/MCP_DEMO/mcp_demo/main.py) —— **服务端启动入口**

- 唯一作用：`mcp_server.run(transport='sse')`，监听 `:8008`
- 顺带 `import mcp_demo.mcp_tools`（副作用：注册 `add` / `multiply`）
- **必须先运行这个文件**，所有客户端才能连上

#### ② [mcp_demo/mcp_server.py](file:///D:/BaiduNetdiskDownload/AI%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%B7%A5%E7%A8%8B%E5%B8%88/02_%E5%BA%94%E7%94%A8%E7%AF%87/11_%E5%9F%BA%E4%BA%8EMCP%E7%9A%84Agent%E5%BC%80%E5%8F%91/00_%E8%AF%BE%E7%A8%8B%E8%B5%84%E6%96%99/MCP_DEMO/MCP_DEMO/mcp_demo/mcp_server.py) —— **服务端定义（核心）**

- 创建 `mcp_server = FastMCP(name='lx-mcp', port=8008)` 实例
- 注册 1 个工具：`my_search_tool`（调智谱联网搜索）
- 注册 2 个资源：
  - `datas://users/{user_id}/email` —— 查邮箱
  - `data://product-categories` —— 商品分类列表
- **核心依赖**：`zhipu_ai.py` 里的 `zhipuai_client`

#### ③ [mcp_demo/mcp_tools.py](file:///D:/BaiduNetdiskDownload/AI%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%B7%A5%E7%A8%8B%E5%B8%88/02_%E5%BA%94%E7%94%A8%E7%AF%87/11_%E5%9F%BA%E4%BA%8EMCP%E7%9A%84Agent%E5%BC%80%E5%8F%91/00_%E8%AF%BE%E7%A8%8B%E8%B5%84%E6%96%99/MCP_DEMO/MCP_DEMO/mcp_demo/mcp_tools.py) —— **额外工具（数学计算）**

- 通过 `@mcp_server.tool()` 装饰器再注册 2 个工具：
  - `add(a, b)` —— 加法
  - `multiply(a, b)` —— 乘法
- 演示"**工具可以拆到不同文件**"的最佳实践
- **必须被 main.py import**，否则这俩工具不会被注册

### 2.3 客户端（4 个文件 + 2 个 langgraph 文件）

所有客户端都通过 `MultiServerMCPClient` 连接 `localhost:8008`，从服务端拿工具和资源。

#### ① [mcp_demo/fastmcp_client.py](file:///D:/BaiduNetdiskDownload/AI%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%B7%A5%E7%A8%8B%E5%B8%88/02_%E5%BA%94%E7%94%A8%E7%AF%87/11_%E5%9F%BA%E4%BA%8EMCP%E7%9A%84Agent%E5%BC%80%E5%8F%91/00_%E8%AF%BE%E7%A8%8B%E8%B5%84%E6%96%99/MCP_DEMO/MCP_DEMO/mcp_demo/fastmcp_client.py) —— **原生 fastmcp 客户端（不依赖 LangChain）**

- 用 `fastmcp.Client` + `SSETransport` 直连
- 三个 RPC：
  - `client.list_tools()` —— 列出工具
  - `client.read_resource('datas://users/567/email')` —— 读资源
  - `client.call_tool(name='add', arguments={"a": 23, "b": 11})` —— 调工具
- **用途**：测试 / 调试 MCP 服务，不涉及大模型

#### ② [mcp_demo/agent_client.py](file:///D:/BaiduNetdiskDownload/AI%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%B7%A5%E7%A8%8B%E5%B8%88/02_%E5%BA%94%E7%94%A8%E7%AF%87/11_%E5%9F%BA%E4%BA%8EMCP%E7%9A%84Agent%E5%BC%80%E5%8F%91/00_%E8%AF%BE%E7%A8%8B%E8%B5%84%E6%96%99/MCP_DEMO/MCP_DEMO/mcp_demo/agent_client.py) —— **LangChain 版 MCP 客户端**

- 用 LangChain 的 `MultiServerMCPClient` 拿工具
- 用 `create_tool_calling_agent` + `AgentExecutor` 让大模型自动选工具
- 示例：`'请计算:10和89的乘积'` → 触发 `multiply`
- **核心依赖**：`zhipu_ai.py` 里的 `llm`

#### ③ [langgraph_mcp/agent_mcp.py](file:///D:/BaiduNetdiskDownload/AI%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%B7%A5%E7%A8%8B%E5%B8%88/02_%E5%BA%94%E7%94%A8%E7%AF%87/11_%E5%9F%BA%E4%BA%8EMCP%E7%9A%84Agent%E5%BC%80%E5%8F%91/00_%E8%AF%BE%E7%A8%8B%E8%B5%84%E6%96%99/MCP_DEMO/MCP_DEMO/langgraph_mcp/agent_mcp.py) —— **LangGraph 自动挡版**

- `MultiServerMCPClient` + `create_react_agent`（LangGraph 内置）
- 异步上下文管理器 `make_agent()` 封装连接生命周期
- 示例：`'计算一下(3+6)的结果'` → 触发 `add`
- **核心依赖**：`zhipu_ai.py` 里的 `llm`

#### ④ [langgraph_mcp/graph_mcp.py](file:///D:/BaiduNetdiskDownload/AI%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%B7%A5%E7%A8%8B%E5%B8%88/02_%E5%BA%94%E7%94%A8%E7%AF%87/11_%E5%9F%BA%E4%BA%8EMCP%E7%9A%84Agent%E5%BC%80%E5%8F%91/00_%E8%AF%BE%E7%A8%8B%E8%B5%84%E6%96%99/MCP_DEMO/MCP_DEMO/langgraph_mcp/graph_mcp.py) —— **LangGraph 手动挡版（自定义状态图）**

- 自己画一张状态图：
  ```
  START → resource(读 MCP 资源) → agent(调 MCP 工具) → END
  ```
- `async_resource` 节点读邮箱资源
- `async_node` 节点调工具生成回答
- `execute_graph()` 提供命令行 REPL（`q` 退出）
- **核心依赖**：`zhipu_ai.py` 里的 `llm`

## 二点五、服务端 vs 客户端 划分（速查）

> 这一节专门回答一个最常被问到的问题：**服务端和客户端各包含哪些文件？谁负责启动？**

### 一句话回答

**是的**——服务端就是 [mcp_demo/](../) 下的 `main.py` + `mcp_server.py` + `mcp_tools.py` 三个文件，客户端就是 [mcp_demo/](../) 下的 `agent_client.py` + `fastmcp_client.py` 加上 [langgraph_mcp/](../) 下的 `agent_mcp.py` + `graph_mcp.py` 共 4 个文件。**启动代码就在 `main.py` 里**。

### 总览图

```
服务端（3 个文件）                  客户端（4 个文件）
┌─────────────────────┐            ┌─────────────────────────┐
│ mcp_demo/main.py    │  ──SSE──▶  │ mcp_demo/fastmcp_client.py │
│   ↓ (启动入口)        │   :8008    │ mcp_demo/agent_client.py   │
│ mcp_demo/mcp_server │            │ langgraph_mcp/agent_mcp.py  │
│   (核心定义)          │            │ langgraph_mcp/graph_mcp.py  │
│ mcp_demo/mcp_tools  │            └─────────────────────────┘
│   (附加工具)          │
└─────────────────────┘
```

### 启动顺序（重要）

```bash
# 第一步（必须先做）：启动服务端
python -m mcp_demo.main
# 此时会监听 :8008，add/multiply/my_search/email/categories 都已注册

# 第二步：另开终端，运行任意一个客户端
python -m mcp_demo.fastmcp_client
# 或
python -m mcp_demo.agent_client
# 或
python -m langgraph_mcp.agent_mcp
# 或
python -m langgraph_mcp.graph_mcp
```

### 为什么 main.py 是"启动入口"而不是 mcp_server.py？

因为 [mcp_demo/main.py](file:///D:/BaiduNetdiskDownload/AI%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%B7%A5%E7%A8%8B%E5%B8%88/02_%E5%BA%94%E7%94%A8%E7%AF%87/11_%E5%9F%BA%E4%BA%8EMCP%E7%9A%84Agent%E5%BC%80%E5%8F%91/00_%E8%AF%BE%E7%A8%8B%E8%B5%84%E6%96%99/MCP_DEMO/MCP_DEMO/mcp_demo/main.py) 里做了 3 件 [mcp_server.py](file:///D:/BaiduNetdiskDownload/AI%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%B7%A5%E7%A8%8B%E5%B8%88/02_%E5%BA%94%E7%94%A8%E7%AF%87/11_%E5%9F%BA%E4%BA%8EMCP%E7%9A%84Agent%E5%BC%80%E5%8F%91/00_%E8%AF%BE%E7%A8%8B%E8%B5%84%E6%96%99/MCP_DEMO/MCP_DEMO/mcp_demo/mcp_server.py) 不会做的事：

1. `import mcp_demo.mcp_tools` —— **触发注册 add/multiply**（关键！少了它，math 工具就用不了）

## 四、判断依据

**怎么判断一个文件是不是 MCP 必需？** 看三个信号：

| 信号 | 检查方法 | 判定 |
|------|---------|------|
| ① 是否被 `mcp_demo/main.py` import | 用 IDE 的"查找引用"看 import 链 | 不被引用 → 演示型 |
| ② 是否连接 `:8008` MCP 服务 | 搜索 `MultiServerMCPClient` / `fastmcp.Client` | 出现 → MCP 必需 |
| ③ 是否在服务端定义工具/资源 | 搜索 `@mcp_server.tool` / `@mcp_server.resource` | 出现 → MCP 必需 |

**套这套规则的结果**：

- ✅ **MCP 必需（9 个文件）**：`env_utils.py`、`zhipu_ai.py`、`mcp_demo/{main, mcp_server, mcp_tools, agent_client, fastmcp_client}.py`、`langgraph_mcp/{agent_mcp, graph_mcp}.py`
- ❌ **演示型（4 个文件）**：`FC/{fc_demo, fc_demo2, fc_demo3}.py`、`agent_demo/zhipu_demo.py`

---

> **维护提示**：未来如果新增演示文件（如 `FC/fc_demo4.py` 或 `agent_demo/another_demo.py`），按上面三个信号判断归类即可；如果是新增 MCP 客户端（如 `mcp_demo/http_client.py`），则归入"二、MCP 完整功能所需文件"。
